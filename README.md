# 📊 Sales Performance Dashboard

## 🔍 Project Overview
The Sales Performance Dashboard is designed to analyze and visualize key business metrics such as sales, profit, and orders. It helps in understanding business performance through interactive and easy-to-read visuals.

## 📈 Key Features
- Total Orders, Sales, Profit, and Average Profit KPIs
- Top 5 Products analysis
- Sales by Category breakdown
- Payment Mode insights (Card, Cash, UPI)
- Monthly Sales & Profit trends
- Region-wise performance analysis
- Interactive filters (Brand, State, City, Category)

## 🛠 Tools Used
- Microsoft Excel
- Data Cleaning & Transformation
- Data Visualization

## 📂 Dataset
- `sales_data.CSV` – Raw sales dataset used for analysis
